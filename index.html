Doc(k)leaner — Orchestrateur d'Audit & Triage CVE

Plateforme centralisée dédiée à l'audit automatisé des images Docker et des scripts d'infrastructure (IaC). Elle corrèle plusieurs moteurs d'analyse pour supprimer les doublons d'alerte et accélérer la remédiation par les équipes DevSecOps.

Temps de scan divisé par 5 Cache mémoire Redis par digest SHA-256
Zéro redondance CVE Corrélation heuristique multi-scanners

Mes responsabilités d'ingénierie sur le projet :

  • Moteur de déduplication & Normalisation CVE : Conception de l'algorithme d'ingestion fusionnant les rapports JSON hétérogènes de plusieurs scanners (Trivy, Grype), élimination des doublons par couche d'image et calcul d'un score de criticité unifié.
  • Architecture de cache & Persistance : Déploiement d'un cache haute vitesse sous Redis indexé sur l'empreinte cryptographique des couches Docker et modélisation de la base PostgreSQL pour l'historisation et le suivi de conformité.
  • API Asynchrone & Workers distribués : Développement du backend FastAPI et orchestration de files de tâches Celery pour absorber les analyses d'images lourdes en parallèle, avec intégration directe en CLI dans les pipelines CI/CD.
Python / FastAPI Redis (Caching) PostgreSQL Celery Docker Trivy & Grype React
